# Portfolio de Saúl Pinedo

Proyecto minimalista hecho con **React + Vite + TailwindCSS**.

## Requisitos
- Node.js 18+

## Instalación
```bash
npm install
npm run dev
```

## Estructura
- `src/components` contiene las secciones: Navbar, Hero, About, Skills, Projects, Contact, Footer.
- Colores principales en `tailwind.config.js` (primary, accent, neutral).

## Personalización
- Edita textos en cada componente.
- Cambia enlaces de GitHub/LinkedIn en `Contact.jsx`.
- Puedes agregar tu `cv.pdf` en la carpeta `public/` y enlazarlo desde el botón del Hero o la Navbar.
